# Contributing to Wallet Dash

Thanks for contributing! A few ground rules:

1. Check the open issues - `good first issue` ones are beginner-friendly.
2. Keep changes small and focused; one issue per pull request.
3. Run the checks before pushing:
   - `npm test`
   - `npm run build`
4. Write or update tests for behavior changes (Vitest + React Testing Library).
5. Testnet first - never paste a mainnet secret anywhere.
6. Be kind in reviews.
